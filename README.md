## 📌 Project Overview

**Bird Species Observation Analysis** is an end-to-end data analysis project that examines National Park Service bird monitoring data across two ecosystems — **Forest** and **Grassland** — to:

- 🔍 **Clean & structure** raw multi-sheet observational data into a single analysis-ready dataset
- 🗄️ **Load & query** the data in MySQL to answer distribution, diversity, and behavior questions in SQL
- 📊 **Visualize insights** through an interactive Streamlit dashboard with live filters across 7 analysis categories

> **Live App:** https://bird-species-observation-analysis-ynz2t8vlng3njrqnscfjqd.streamlit.app/

---

## 🧠 Problem Statement

The project analyzes the distribution and diversity of bird species across two distinct ecosystems — forests and grasslands — to understand how environmental factors such as vegetation type, climate, and terrain influence bird populations and behavior. By identifying habitat preference patterns and diversity differences between the two ecosystems, the findings support habitat conservation, biodiversity management, and assessment of environmental change impacts on avian communities.

**Business Use Cases:**
- 🌳 **Wildlife Conservation** — inform decisions on protecting critical bird habitats
- 🏞️ **Land Management** — optimize land use and restoration strategies
- 🦅 **Eco-Tourism** — identify bird-rich areas to develop bird-watching tourism
- 🌾 **Sustainable Agriculture** — support practices that minimize impact on grassland/forest bird populations
- 📋 **Policy Support** — data-driven insights for conservation policy on vulnerable species
- 📈 **Biodiversity Monitoring** — track ecosystem stability through avian population health

## 📊 Dataset

| Column (examples) | Description |
|---|---|
| Common_Name / Scientific_Name | Species identity |
| Date, Start_Time, End_Time | When the observation occurred |
| Admin_Unit_Code, Plot_Name | Where the observation occurred (park / plot) |
| Temperature, Humidity, Sky, Wind | Environmental conditions during observation |

| PIF_Watchlist_Status, Regional_Stewardship_Status, AOU_Code | Conservation status indicators |

**Dataset stats (after cleaning):**
- Combined rows: 15,372 (from two raw files, 11 admin units each)
- Unique species: 127 (108 in Forest, 107 in Grassland)
- Habitats: Forest, Grassland
- Coverage: 2018, Spring & Summer seasons

## 🔧 Project Workflow

### Step 1 — Data Upload & Preprocessing
- Load all 11 sheets from both FOREST and GRASSLAND workbooks, tag each row with its habitat
- Combine into a single dataframe (Forest-only and Grassland-only columns are preserved, not dropped)
- Standardize data types (dates, numeric fields) and text fields

### Step 2 — Data Cleaning
- Remove exact duplicate rows
- Document schema differences between habitats (`Site_Name`/`NPSTaxonCode` are Forest-only, `Previously_Obs` is Grassland-only) rather than treating them as missing-data errors
- Derive `Season` and `Start_Hour` for temporal analysis

### Step 3 — Exploratory Data Analysis
12 charts across 7 categories: Temporal, Spatial, Species, Environmental Conditions, Distance & Behavior, Observer Trends, Conservation Insights.

### Step 4 — SQL Analysis
Cleaned data loaded into MySQL (`bird_observations` table); the same 7 categories re-expressed as SQL queries in `bird_queries.sql`.

### Step 5 — Streamlit Dashboard
Three-page interactive dashboard: Problem Statement & Business Use Cases, a filterable multi-tab Dashboard, and Insights & Recommendations.

## 🚀 How to Run Locally

**1. Clone the repository:**
```bash
git clone https://github.com/abhi-1009/bird-species-observation-analysis.git
cd bird-species-observation-analysis
```

**2. Create a virtual environment:**
```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux
```

**3. Install dependencies:**
```bash
pip install -r requirements.txt
```

**4. Set up MySQL:**
- Create a database: `CREATE DATABASE bird_observations;`
- Create your own `config.py` with `DB_PASSWORD = "your_password"` (this file is gitignored — you must create it locally)

**5. Run the data pipeline** (cleans data, generates charts, loads MySQL):
```bash
python birds_analysis.py
```

**6. Launch the Streamlit app:**
```bash
streamlit run birds_analysis_streamlit.py
```
Opens at `http://localhost:8501`.

> ⚠️ `birds_analysis_streamlit.py` is a Streamlit app — always launch it with `streamlit run`, never as a plain Python file.

## 📌 Key Business Insights

- 🏞️ **Certain parks and plots consistently show higher species diversity** — direct candidates for conservation priority or eco-tourism development
- 🌡️ **Environmental conditions shape observability** — temperature and disturbance level visibly relate to observation distance and counts
- ⚠️ **A small but critical subset of species are conservation priorities** — those flagged under PIF Watchlist or Regional Stewardship status
- 🧭 **Spatial analysis relies on plot/admin-unit codes, not GPS** — a noted limitation, since the dataset doesn't include coordinates
- 👥 **Only 3 observers contributed data** — a known observer-bias risk worth disclosing alongside any species-level conclusions
